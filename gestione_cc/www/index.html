Collega Google Drive

Dal PC Windows crea un OAuth Client ID di tipo “Desktop app” nella Google Cloud Console, abilita Google Drive API e usa il comando rclone indicato qui sotto. Incolla poi il token JSON generato.

rclone authorize drive --drive-scope drive.file --drive-client-id "CLIENT_ID" --drive-client-secret "CLIENT_SECRET"

Conservazione: 1 backup di sessione e gli ultimi 3 backup notturni (ore 03:00, ora italiana). Il backup alla chiusura della scheda è un tentativo; il comando Esci attende il completamento.
